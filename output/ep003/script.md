# 第3集: 误会升级与禁欲失控

## 场景1: [公司办公室] 白天
**场景描述**: 苏浅坐在办公桌前，手机屏幕闪烁着刺眼的光，周围同事指指点点。

[苏浅]: (看着手机，手颤抖) 又是这种新闻？
(情绪提示: 委屈/心碎)

[同事A]: (凑近，阴阳怪气) 苏小姐，顾总真是深不可测啊。

[苏浅]: (咬牙，合上电脑) 别说了，我累了。
(情绪提示: 压抑怒火)

[动作描述]: 苏浅深吸一口气，将散落的文件整齐装入黑色行李箱。她最后看了一眼办公室，眼神黯淡无光。

## 场景2: [机场VIP通道] 白天
**场景描述**: 机场内人来人往，广播催促登机。苏浅拖着箱子，步履沉重地走向闸口。

[顾言深]: (气喘吁吁跑来，衬衫凌乱) 苏浅！
(情绪提示: 焦急/慌乱)

[苏浅]: (头也不回，脚步加快) 别拦我，顾总。

[顾言深]: (一把拉住她的手腕，声音发颤) 别走……信我一次。
(情绪提示: 近乎哀求)

[苏浅]: (甩开手，冷笑) 信你？信你夜会红颜？

[顾言深]: (举起手中文件，额头渗汗) 视频是假的！鉴定报告在这！
(情绪提示: 急切/恳切)

[动作描述]: 顾言深将报告递过去，眼神从未有过的无助。他平日里高高在上的禁欲感此刻崩塌，只剩下对失去她的恐惧。

[苏浅]: (接过报告，手指微动) 这能证明什么？

[顾言深]: (握住她的手，拇指摩挲) 证明我只爱你。别闹，专心点看我。
(情绪提示: 深情/坚定)

[苏浅]: (抬头看他，眼眶泛红) 言深……我差点就信了。
(情绪提示: 感动/动摇)

## 场景3: [机场大厅] 白天
**场景描述**: 突然，一阵骚动。林婉儿带着三个手持直播镜头的记者冲入大厅，闪光灯疯狂闪烁。

[记者A]: (举着手机直播) 家人们看！顾总果然在这里！

[林婉儿]: (假惺惺地挥手) 顾总，您还没解释清楚呢，怎么就急着结婚？
(情绪提示: 得意/挑衅)

[苏浅]: (后退一步，脸色苍白) 又是你……

[顾言深]: (眼神瞬间冷冽，挡在苏浅身前) 滚出去。
(情绪提示: 暴怒/冰冷)

[林婉儿]: (假装委屈，放大声音) 哎呀，顾总别这么凶嘛。我只是担心苏小姐……
(情绪提示: 绿茶/伪装)

[动作描述]: 顾言深猛然转身，一把将苏浅拉入怀中，紧紧禁锢。他对着镜头，气场全开，眼神如刀。

[顾言深]: (对着镜头，声音低沉有力) 她是我顾言深唯一的妻子。谁敢造谣，顾家法务部见。
(情绪提示: 霸道/宣示主权)

[动作描述]: 人群被顾言深的气势震慑，纷纷后退。记者们有些慌乱，但林婉儿却趁乱悄悄按下了手机外放键。

[苏浅]: (在他怀里放松下来，轻声) 言深，谢谢你。

[顾言深]: (低头吻她发顶，温柔) 没事了，我在。

[动作描述]: 就在苏浅感动得闭眼享受这一刻宁静时，顾言深的西装口袋突然传出刺耳的铃声。
他眉头一皱，掏出手机。
屏幕亮起：来电显示“林婉儿”。

[顾言深]: (犹豫片刻，接通并开启免提) 有事快说。

[林婉儿]: (声音通过外放清晰传来，带着恶毒的笑意) 顾总，你太太的“过敏药”里，可是加了让我怀孕的药哦……
(情绪提示: 阴狠/幸灾乐祸)

[动作描述]: 顾言深瞳孔骤缩，整个人如遭雷击。他猛地抬头，死死盯住怀里的苏浅，原本温柔的眼神瞬间变得复杂而惊恐。

[苏浅]: (察觉异样，疑惑地抬头) 言深？你怎么了？

[顾言深]: (嘴唇颤抖，不敢置信) 药……？

[动作描述]: 周围空气仿佛凝固。顾言深手中的手机滑落，苏浅脸上的笑容僵住，眼神逐渐从疑惑转为震惊和恐惧。
